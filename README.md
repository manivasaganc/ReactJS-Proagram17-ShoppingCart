# Shopping Cart Using useReducer

## 📌 Project Description

This project demonstrates how to build a simple shopping cart in React.js
using the `useReducer` hook.

Users can:

- View products.
- Add products to the cart.
- Increase the quantity of an existing product.
- Remove products from the cart.
- Clear the entire cart.
- View the total cart price.

## 🎯 Objective

Create a React shopping cart using `useReducer` to manage the cart state.

The application should implement the following actions:

- `ADD_TO_CART`
- `REMOVE_FROM_CART`
- `CLEAR_CART`
